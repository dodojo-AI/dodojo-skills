dodojo 的开源 Agent Skills。dodojo-travel 把一趟行程做成路上能用的一页，营业时间和门票按出行当天核实，路线不走回头路，配真实照片和地图；dodojo-game 做一页打开就能玩的游戏，游戏在最上面，电脑对手分档，每一步都存着。每个 skill 都是一套做法而不是模板。连上 dodojo，它会先翻你存过的东西，做好后直接存进你的记忆库。Open agent skills from dodojo. dodojo-travel turns a trip into a page you follow on the road: hours and tickets checked for your dates, a route that never backtracks, real photos and a map. dodojo-game makes a game you play on one page: the game on top, a computer opponent with real levels, every move kept. Each skill is a way of working, not a template. Connected to dodojo, it starts from what you already keep and saves the result into your library.

一个 skill 怎么变成一页How a skill becomes a page

  1. 你说一句话You ask「帮我排个京都东山一日游」。连上 dodojo 时，Agent 先翻你存过的订单、收藏和笔记。"Plan me a day in Kyoto's Higashiyama." With dodojo connected, the agent first looks through your bookings, saved places and notes.
  2. Agent 按 skill 做事The agent follows the skillskill 写的是方法：查什么、怎么排、设计怎么定、做完怎么检查。不是模板，所以每个主题长得不一样。A skill is a method: what to check, how to plan, how to design and how to check the result. Not a template, so every subject gets its own look.
  3. 得到一页能用的东西You get a page to keep一个 HTML 文件，任何浏览器都能打开。存进 dodojo 就是一条网页笔记，勾过的清单会记住。One HTML file that opens in any browser. In dodojo it is a webpage Note that remembers what you ticked.

配合 dodojo 用With dodojo

在 Agent 里连接 dodojo 的 MCP（https://www.dodojo.ai/api/mcp，登录一次），skill 就能搜你的记忆、把页面存成笔记。dodojo 桌面版里的 Agent 已经连好。不连也能用：页面存成本地文件。Connect your agent to dodojo's MCP server (https://www.dodojo.ai/api/mcp, sign in once) and the skills can search your memories and save pages as Notes. The agent in the dodojo desktop app is already connected. Without it, pages are saved as local files.
